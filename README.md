🚀 Acerca del Proyecto

GameHub-Store es una interfaz de tienda de videojuegos diseñada para ofrecer una experiencia de usuario fluida, organizada y atractiva. El proyecto implementa componentes reutilizables en React, gestión eficiente de estados y empaquetado optimizado mediante Vite.

🛠 Tecnologías Utilizadas

El proyecto está construido utilizando las siguientes tecnologías y herramientas modernas de desarrollo web:

Frontend: React (Biblioteca principal de interfaces de usuario).

Empaquetador y Entorno: Vite (Herramientas de construcción rápida).

Internacionalización y Utilidades: @internationalized/date, @internationalized/number, @internationalized/string.

Herramientas de Calidad de Código: Oxlint (Linter de alto rendimiento).

Transpilación: Babel Runtime.

⚙️ Requisitos Previos

Asegúrate de contar con lo siguiente instalado en tu entorno local antes de comenzar:

Node.js (Versión 18.x o superior recomendada).

npm (Gestor de paquetes incluido con Node.js).

Abre tu navegador web y accede a la dirección local proporcionada por Vite (usualmente http://localhost:5173).
